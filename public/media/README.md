# Необязательные ассеты

Файлы из этой папки подхватываются автоматически. Если их нет, игра
использует встроенные замены (процедурная музыка, CSS-текстуры), поэтому
проект собирается и работает в любом случае.

| Файл | Что делает | Требования |
|---|---|---|
| `music/theme.mp3` | Фоновая музыка вместо синтезированной темы | зацикливаемый фрагмент 60–120 с, mp3 128–160 kbps, до 2 МБ, без резкого начала |
| `textures/paper.jpg` | Текстура бумаги на карточке документа | светлая, малоконтрастная, бесшовная, 1200×1600, до 300 КБ |
| `textures/backdrop.jpg` | Фон сцены под градиентами | тёмная, 2000×1200, до 400 КБ |
