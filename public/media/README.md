# Ассеты

Файлы из этой папки подхватываются автоматически. Если файла нет, игра
использует встроенную замену (процедурная музыка, CSS-текстуры), поэтому
проект собирается и работает в любом случае.

| Файл | Что делает | Статус |
|---|---|---|
| `menu/headquarters.webp` | Фон главного меню: здание компании | есть |
| `textures/paper.webp` | Текстура бумаги на карточке документа | есть |
| `textures/backdrop.webp` | Фон сцены под градиентами | есть |
| `ui/logo.webp` | Логотип в меню вместо нарисованного флага | есть |
| `ui/stamp-stop.webp` | Печать «ОСТАНОВЛЕНО» | есть |
| `ui/stamp-pass.webp` | Печать «ПРОВЕРЕНО» | есть |
| `ui/stamp-fail.webp` | Печать «ОШИБКА» | есть |
| `ui/stamp-warn.webp` | Печать «ВРЕМЯ ВЫШЛО» | есть |
| `ui/panel-frame.webp` | Рамка карточек разбора, итогов и окон | есть |
| `ui/button-frame.webp` | Рамка главной кнопки экрана | есть |
| `menu/office-night.webp` | Фон итогового экрана | есть |

| `music/theme.mp3` | Фоновая музыка вместо синтезированной темы | нет, играет синтез |

## Требования к новым файлам

- **Музыка** — зацикливаемый фрагмент 60–120 с, mp3 128–160 kbps, до 2 МБ,
  без резкой атаки в начале и в конце, иначе петля будет щёлкать.
- **Текстура бумаги** — светлая, малоконтрастная, бесшовная, до 300 КБ.
  Накладывается в режиме multiply, поэтому тёмные пятна проявятся на документе.
- **Фон сцены** — тёмная поверхность, до 400 КБ, ложится под градиенты с
  прозрачностью 30%.
- **Фон меню** — горизонтальный кадр 16:9, до 400 КБ. Центр кадра перекрывается
  заголовком и кнопками, поэтому главное должно читаться по краям.

Расширение подбирается автоматически: проверяются `.webp`, `.png`, `.svg`
и `.jpg`. Пути собраны в одном месте — `src/core/assets.ts`, объект `MEDIA`.
