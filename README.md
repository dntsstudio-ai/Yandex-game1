# Последнее убежище

Браузерная инди-игра для Яндекс Игр: менеджмент подземного убежища, экспедиции с риском/наградой, событийные выборы.

Статус: **фаза планирования**. Код ещё не написан — см. документы ниже.

## Документация

- [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md) — фазы разработки и задачи
- [GAME_DESIGN.md](./GAME_DESIGN.md) — игровой дизайн
- [ARCHITECTURE.md](./ARCHITECTURE.md) — технический стек и структура проекта

## Запуск (после Phase 0)

```
npm install
npm run dev
```

Сборка продакшн-бандла:

```
npm run build
```
